# Блок 2. Excel

## 1. `Testirovanie_Analitik_solution.xlsx`
- **Лист1** — Лист1 и Лист2 объединены: количество складов/заказов/клиентов подтянуто формулами `SUMIFS` по ключу «Дата + Территория»; рассчитаны «Товарооборот на склад» (= руб / склады) и «Неделя» (`WEEKNUM(дата;21)`, ISO-неделя).
- **Сводная** — 1.1 две сводные таблицы «Территория × Неделя» (товарооборот, руб и товарооборот на склад); расчёт долей и рангов; **ТОП-3**:
  - по доле от общего товарооборота: Санкт-Петербург Север (27,8%), Санкт-Петербург Юг (20,9%), Москва Запад (15,6%);
  - по товарообороту на склад за последнюю неделю: Москва Восток, Москва Запад, Санкт-Петербург Север (одинаково для последней полной нед. 22 и для неполной нед. 23).
- **Динамика** — 1.2 комбинированный график недельной динамики общего товарооборота (столбцы) и товарооборота на склад (линия, вторая ось) по всем территориям, а также линии ТОП-6 территорий.

## 2. `Assignment_solution.xlsx`
- **Diagrams** — 4 графика: продажи по товарам (шт.), выручка по товарам с итогом, структура выручки (кольцевая), динамика Total sales; вспомогательная таблица выручки; выводы.
- **Structuring** —
  1. данные приведены в табличный вид в серой области (D22:M322);
  2. добавлен `market_desc` (VLOOKUP по справочнику);
  3. общий трафик в ГБ (upload + download, МБ/1024) и сегментация с шагом 5 ГБ до 50+ ГБ (LOOKUP по нижним границам в колонке «Категория»);
  4. сводная таблица: абоненты по городам с разворотом до типа клиента и «% от всех абонентов», **фильтр по модему** — поле `modem` в фильтре сводной + автофильтр на таблице;
  5. условное форматирование, таблицы и графики по сегментам трафика и модемам, выводы.
- **AB test** — 21 644 номера разбиты на Test (3 000), Control (3 000) и Out of test. Стратифицированная случайная выборка (регион × смартфон × дециль ARPU), проверка равенства групп: ARPU t-тест p = 0,96, Манн–Уитни p = 0,96; регион χ² p ≈ 1,0; смартфон χ² p = 1,0.
- **Hidden** — скрытый лист найден и сделан видимым.

Все расчёты — формулами, поэтому значения пересчитываются при открытии в Excel.
